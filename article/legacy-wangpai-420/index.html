机场订阅怎么用？Windows、Mac、安卓与 iPhone 图解

订阅与客户端教程 · 2026-10-04 · 6 分钟阅读

机场订阅买完怎么用？按Windows、Mac、安卓和iPhone说明客户端下载、订阅导入、节点选择与连接开关，附五张原创示意图和连不上时的排查表。

正文

机场订阅并不复杂：准备好有效套餐和私人订阅链接，然后在自己的设备上完成导入和连接。本文用步骤图讲清第一次怎么做。

记住顺序：注册或试用 → 安装软件 → 复制订阅 → 导入节点 → 开启连接。

1. 先分清：机场、订阅、客户端

- 机场：提供网络线路的服务商，通常按套餐收取费用。

- 订阅链接：属于你账号的私人地址，用来把线路导入软件。

- 客户端：装在电脑或手机上的连接软件；节点就是可选择的线路。

只看自己使用的设备部分即可，不需要把三款软件都装上。

2. 注册或领取试用，拿到自己的订阅链接

尚未选服务商，可以先看FlyBit 与 99吧的入口及试用核对，或用机场选购清单比较其他候选。推荐页含邀请推广链接；先确认试用权益和客户端兼容，再决定是否付款。已经有有效订阅，可直接跳到自己的设备部分。

- 在自己选择的服务商官网注册并登录。

- 看清流量、有效期、设备数量和同时在线限制，按需选短期或试用套餐。

- 领取试用或按需购买后，在后台确认权益已生效、仍有可用流量。

- 找到“我的订阅 / 复制订阅 / 一键导入”，复制与你的软件匹配的订阅格式。

不要复制官网、订单页或登录页的网址。 如果服务商不支持表中某款软件，先问客服应该用哪款客户端。别把私人订阅地址贴到陌生的在线转换网站。

3. 电脑端：Windows 和 Mac

使用 Clash Verge Rev，步骤如下：

- 安装。 从官方安装文档进入正式发布页。Windows 下载与系统类型对应的 x64 / ARM64 安装包；Mac 按 Apple 芯片或 Intel 选择，打开安装包后移到“应用程序”。

- 导入。 复制 Clash / mihomo 兼容订阅，打开客户端的订阅页，在链接输入栏粘贴，点导入。

- 选线路。 选中刚导入的配置，再到代理页选择一个可用节点，模式先用规则。

- 开连接。 打开系统代理开关，再用浏览器访问自己需要的网页。

[图片：电脑端安装软件、导入配置、选择节点、打开系统代理并测试网页的五步示意]

Windows 可在“设置 → 系统 → 关于”查看系统类型；Mac 可在“关于本机”查看芯片。当前官方安装说明要求 Windows 10/11、macOS 12 或以上，旧系统先核对兼容性。

完成标志：目标网页正常加载，刷新后仍能打开。 系统代理适合先完成浏览器使用；其他软件不走系统代理时，再按官方快速入门了解 TUN，不用一开始就改复杂设置。订阅导入说明

4. 安卓手机：v2rayNG

- 安装。 从v2rayNG 官方正式发布页下载 APK；不知道选哪个时看官方安装包说明。

- 新增订阅。 打开订阅分组（旧版可能叫“订阅分组设置”），点“+”；备注填“我的订阅”，URL 粘贴 v2rayNG / V2Ray 兼容订阅，保存。

- 更新并选节点。 找到更新订阅，更新后等待节点出现，再点选一个节点。保存地址以后，还需要更新。

- 启动。 点客户端的启动 / 连接按钮；首次系统弹出 VPN 请求，确认应用名称是 v2rayNG，再点确定 / 允许。

- 测试。 用浏览器打开目标网页，能正常加载才算完成。

[图片：安卓手机添加订阅分组、填写URL、更新节点、启动及允许VPN的步骤图]

VPN 提示是安卓系统的连接授权，不是让你再买一份套餐。钥匙或 VPN 图标只代表接口已启动，还要实际打开网页。下载时优先正式版；测试版界面和功能可能变化。

5. iPhone：Shadowrocket（小火箭）

- 安装。 从App Store 官方页面核对名称 Shadowrocket、开发者 Shadow Launch Technology Limited。它单独收费，价格及可下载地区以你自己的商店页面为准，不附送机场线路。

- 添加订阅。 打开客户端，点“+”，类型选择 Subscribe / 订阅；URL 粘贴 Shadowrocket 兼容订阅，填备注并点完成。

- 选节点。 等待节点列表出现，点选一条线路；未出现时先更新订阅。服务商提供“一键导入 Shadowrocket”时，也可使用该入口。

- 开启。 打开首页连接开关，按系统提示允许添加 VPN 配置并完成验证。

- 测试。 打开 Safari 访问目标网页，确认能加载和刷新。

[图片：iPhone添加Subscribe订阅、填写URL、选择节点及允许VPN配置的步骤示意]

商店里找不到时，先询问服务商支持哪些可下载的 iPhone 客户端，使用对应订阅格式。安卓 APK 无法安装到 iPhone。

[图片：连接失败时依次检查订阅、连接开关、节点和套餐的四项清单]

给第一次使用的你： 客户端软件和机场服务分别提供不同功能；安装客户端不会自动获得线路，买了套餐也仍需导入订阅。

7. 下次怎么用，怎么关闭

节点有变化时更新订阅，通常不用重装软件。电脑不用时先关闭系统代理，再退出客户端；手机关闭连接开关。

订阅地址和二维码别公开；求助截图先遮盖。电脑与手机同时使用能否成功，还要遵守套餐的设备限制。

最后检查：套餐有效 → 节点出现 → 连接已开 → 网页能打开。
